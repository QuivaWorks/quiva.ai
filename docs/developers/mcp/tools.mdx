This is a generated reference, not hand-written — each server's tools are listed exactly as it registers them. Names are shown **without** their remote prefix (see [Tool prefixes](/developers/mcp/overview#tool-prefixes)); running a server locally, use the bare name.

<Info>
**Write** / **Delete** in the Notes column is a naming-convention heuristic (verbs like `create_`, `update_`, `delete_`, `publish_`), not a full side-effect audit — a handful of read-shaped tools still cause something to happen (`run_workflow` executes a flow, `invoke_agent` spends LLM tokens). `confirm: true` means the tool refuses to run until you pass that flag explicitly, because the change is broad, hard to undo, or costs money.
</Info>
